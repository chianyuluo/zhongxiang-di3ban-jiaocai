# 案例找错教练（中项）

## R｜原文/考纲锚点（≤150字）

应用技术通常 **4 道案例题**（3 道分析 + 1 道计算，计算约 18–22 分）。找错题要求指出问题并给出正确做法，按点给分；只写"不对"不得分。

## I｜考生通常卡在哪

1. **凭感觉找**，漏维度。
2. **只从进度/成本找**，漏风险、沟通、干系人。
3. **把现象当问题**："延期了"不是问题，"未做进度控制"才是。
4. **只说不改**。
5. **不分点**。

**经验**：风险、沟通、干系人最易漏。

## A1｜十维扫描清单

| 维度 | 典型症状 |
|---|---|
| 整合 | 无项目管理计划、变更未走 CCB |
| 范围 | WBS 未到工作包、范围蔓延、未确认范围 |
| 进度 | 无基准、关键路径被压缩、赶工无预案 |
| 成本 | 无成本基准、超支无纠偏 |
| 质量 | 管理质量/控制质量颠倒、无质量审计 |
| 资源 | 角色不清、无培训、冲突未解决 |
| 沟通 | 无沟通计划、信息不同步 |
| 风险 | 未识别、无登记册、无应对计划 |
| 采购 | 合同类型选错、未控制采购 |
| 干系人 | 未识别全、未分析权力/利益 |

**答题格式**
> 问题：____；原因：未执行____过程；措施：应____。

## A2｜反例库

**反例 A：只从成本找**
- 过程："只写成本超支。"
- 错在哪：漏风险、沟通、干系人。
- 追问："风险维度有信号吗？干系人呢？"

**反例 B：现象当问题**
- 过程："问题是项目延期。"
- 错在哪：应写"未进行进度控制/未及时纠偏"。
- 追问："项目经理缺少哪个具体动作？"

**反例 C：只说不改**
- 过程："他没走变更流程。"
- 错在哪：没有正确做法。
- 追问："正确做法写成一个动作。"

## E｜执行流程（每层只问一个问题）

1. **扫描**："十个维度，各有没有信号？"
2. **转动作**："这条是现象还是管理动作缺失？"
3. **三段式**："原因和措施分别是什么？"
4. **分点**："一共几条？按问题/原因/措施排好。"

## 使用示例

**考生**："我只看出进度延误。"

**响应**："先放下进度。风险维度题干有没有'未识别/无应对'？沟通有没有'未汇报'？干系人有没有'不满意/未参与'？"

## B｜边界

1. 不给完整参考答案。
2. 不处理计算（转 `04`/`05`）。
3. 不替代十大领域系统学习。
