# 错题归因日志（中项）

## R｜原文/考纲锚点（≤150字）

中项两科同一次均 ≥45，单科不保留。跨题归因把零散错题收敛成 2–3 个系统性弱点，决定复习优先级。

## I｜考生通常卡在哪

1. **逐题过不归因**。
2. **归因太粗**："基础不好"。
3. **不分优先级**。

## A1｜正确归因示范

**5 道错题**：2 道管理质量/控制质量、1 道过程组归属、1 道挣值取数、1 道等保级别。

1. 2 道质量过程 → 系统性弱点 → 补 `03` + `ch12`
2. 1 道过程组 → 单点
3. 1 道挣值 → 单点
4. 1 道等保 → 单点
5. 结论："本周优先补管理质量/控制质量，其余随每日训练。"

**归因表**
```
日期 | 来源 | 标签 | 具体错点 | 回补动作 | 是否已补
```

**五类标签**：知识盲区 / 概念混淆 / 审题遗漏 / 计算步骤 / 表述不规范。

## A2｜反例库

**反例 A：归因太粗**
- 过程："我基础不好。"
- 错在哪：不可执行。
- 追问："具体哪个领域、哪类错误？"

**反例 B：不分类**
- 过程：5 道都列"重点"。
- 错在哪：优先级不清。
- 追问："哪几道同类？"

**反例 C：粗心当原因**
- 过程："这题粗心。"
- 错在哪：下次还错。
- 追问："具体哪一步没看清？"

## E｜执行流程（每层只问一个问题）

1. **列清单**："错题列出来，标知识点。"
2. **聚类**："哪几道同类？出现 2 次以上列系统性弱点。"
3. **指向**："对应哪个教练/章节？"
4. **复验**："三天后同类型 3 道题。"

## 使用示例

**考生**："我错了好多。"

**响应**："先列 10 道，每题写一句考什么。按知识点聚类，通常只有 2–3 个真弱点。"

## B｜边界

1. 不做单题解析（转 `01`）。
2. 不替代训练。
3. 不保证一次归因到位。
