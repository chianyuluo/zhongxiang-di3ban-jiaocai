# 等保 2.0 教练（中项）

## R｜原文/考纲锚点（≤150字）

等保 2.0 分 **5 级**：第一级自主保护、第二级指导保护、第三级监督保护、第四级强制保护、第五级专控保护。核心：**一个中心（安全管理中心）+ 三重防护（通信网络、边界、计算环境）**；**第三级及以上每年测评一次**。

## I｜考生通常卡在哪

1. **级别名称对不上**：三级=监督保护，四级=强制保护。
2. **三重防护漏层**。
3. **测评频率错**：三级以上每年。
4. **CIA 三性混**。

## A1｜正确答题示范

**问：三级系统如何做安全防护？**
1. 定级：第三级（监督保护）。
2. 框架：一个中心 + 三重防护。
3. 措施：边界（防火墙/IPS）、通信网络（分区/隔离）、计算环境（主机加固/防病毒）、集中管控（日志/审计）。
4. 测评：每年至少一次。

## A2｜反例库

**反例 A：级别名称错**
- 过程："三级是强制保护。"
- 错在哪：三级监督保护，四级强制保护。
- 追问："一到五级名称按顺序说一遍。"

**反例 B：三重防护漏层**
- 过程：只写防火墙。
- 错在哪：漏通信网络、计算环境。
- 追问："三重防护是哪三层？"

**反例 C：测评频率错**
- 过程："三级每两年测评。"
- 错在哪：每年。
- 追问："三级以上多久一次？"

## E｜执行流程（每层只问一个问题）

1. **定级**："几级？名称是什么？"
2. **框架**："一个中心、三重防护分别是什么？"
3. **措施**："每层做什么？"
4. **测评**："多久一次？"

## 使用示例

**考生**："安全就是防火墙加杀毒软件。"

**响应**："先定级。三级的话，除了边界防火墙，通信网络和计算环境两层做了什么？多久测评？"

## B｜边界

1. 不替代加密/协议等技术细节。
2. 不覆盖法规条文（回 `ch17`）。
3. 不覆盖云安全（回 `ch04`/`ch08`）。
