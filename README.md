# 软考中项（系统集成项目管理工程师）第 3 版 · 备考 Skill

> 把《系统集成项目管理工程师教程（第 3 版）》结构化提炼而成的 agent skill，供 WorkBuddy / Claude 等支持 skills 的 AI 助手调用，辅助软考中项备考（知识点梳理、案例找错、考点速记、出题）。

## 这是什么
- **不是教材原文，而是框架型提炼**：每章抽取 Core Idea / Frameworks / Key Concepts / Mental Models / Anti-patterns / Takeaways，便于快速取料与出题。
- 覆盖：18 章知识框架、**五大过程组（启动2/规划24/执行10/监控11/收尾1=48过程）**、ITSS 与 IT 服务生命周期、等保2.0、信息系统架构、软件工程、数据工程、系统集成、监理、法律法规与职业道德、速记清单、术语表、案例反模式。

## 目录结构
- `SKILL.md`：主索引（框架 / 原则 / 技法 / 反模式层）
- `chapters/ch01~ch18.md`：18 章结构化笔记
- `cheatsheet.md`：过程数 / 口诀 / 决策规则速查
- `glossary.md`：核心术语
- `patterns.md`：案例找错反模式 / 过程组匹配 / 选型套路

npx skills add chianyuluo/zhongxiang-di3ban-jiaocai
