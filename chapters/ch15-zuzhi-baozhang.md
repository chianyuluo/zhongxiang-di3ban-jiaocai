# Chapter 15: 组织保障

## Core Idea
本章讲项目落地的组织支撑：项目组织类型与结构、项目经理的角色与能力、团队建设与管理、项目管理制度，是"人"与"制度"层面的保障章。

## Frameworks Introduced
- **项目组织 3 类型**：
  - 职能型：按专业部门划分，项目经理权限小。
  - 项目型：项目独立成军，项目经理权限大、资源独占。
  - 矩阵型：弱矩阵（偏职能）/ 平衡矩阵 / 强矩阵（偏项目），兼顾资源复用与项目聚焦。
- **项目经理能力三角**：技术项目管理 / 领导力 / 战略与商务管理。
- **团队建设**：塔克曼阶梯（形成→震荡→规范→成熟→解散）；激励（马斯洛/赫茨伯格）。
- **项目管理制度**：章程、流程、规范、考核与奖惩机制。

## Key Concepts
- **责任分配矩阵（RAM/RACI）**：谁负责(R)、 accountable(批)、consulted(咨)、informed(知)。
- **虚拟团队**：跨地域协作，需强沟通机制。
- **组织过程资产**：模板、历史库、流程资产（项目可复用）。

## Mental Models
- 选组织结构：要资源复用→矩阵；要专注交付→项目型；要专业深耕→职能型。
- 团队冲突高发于"震荡期"，靠规范与领导化解。

## Anti-patterns
- 强矩阵项目却用职能型考核，导致项目经理有责无权。
- 重技术轻制度，项目靠个人英雄主义而非流程。

## Key Takeaways
1. 组织 3 型：职能/项目/矩阵（弱-平衡-强）。
2. 项目经理能力三角：技术/领导/战略商务。
3. 团队按塔克曼阶梯发展；RACI 明确分工。
4. 制度是可持续交付的保障。
