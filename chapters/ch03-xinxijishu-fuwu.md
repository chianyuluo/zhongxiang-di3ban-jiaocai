# Chapter 3: 信息技术服务

## Core Idea
本章引入 IT 服务的标准化体系 ITSS，以及 IT 服务生命周期与服务质量模型，是系统集成项目"交付与运维"的理论基础，也是中项案例/选择题的高频章。

## Frameworks Introduced
- **ITSS（信息技术服务标准）**：我国自主的 IT 服务标准体系，覆盖能力建设、服务管控、业务标准等。
- **IT 服务生命周期 5 阶段**：规划设计 → 部署实施 → 服务运营 → 持续改进 → 监督管理（注意顺序：先规划、再部署、进运营、常改进、强监督）。
- **IT 服务四要素（ITSS 视角）**：人员（People）、过程（Process）、技术（Technology）、资源（Resource）——即 PPTR（中项/ITSS 用 PPTR，与系规第2版的"人员/资源/技术/过程"表述不同，注意区分）。
- **服务质量模型**：安全性、可靠性、响应性、有形性、友好性（5 大特性）。
- **运维服务能力成熟度**：从基础级到提升级的分级模型。

## Key Concepts
- **服务 vs 产品**：服务具有无形性、不可分离性、差异性、不可存储性。
- **SLA（服务级别协议）**：服务供需双方约定的质量契约。
- **服务目录**：对外提供的服务清单。

## Mental Models
- 交付类案例：先"规划设计"定 SLA 与资源，再"部署实施"，转入"服务运营"，用"监督管理"把控，靠"持续改进"提升。
- ITSS 四要素 PPTR 与系规"人员/资源/技术/过程"顺序不同，答题按所考科目对应表述。

## Anti-patterns
- 在系规科目里写 ITSS 的 PPTR（系规第2版固定为人员/资源/技术/过程）。
- 把 IT 服务生命周期阶段顺序记错（规划设计在前、监督管理在后）。

## Key Takeaways
1. ITSS 是我国 IT 服务标准；生命周期 5 阶段顺序固定。
2. ITSS 四要素 = PPTR（与系规表述口径不同）。
3. 服务质量 5 特性：安全/可靠/响应/有形/友好。
4. SLA 是服务质量契约。
