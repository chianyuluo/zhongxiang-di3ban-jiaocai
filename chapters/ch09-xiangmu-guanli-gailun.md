# Chapter 9: 项目管理概论

## Core Idea
本章奠定项目管理的全局认知：什么是项目、项目与运营/项目集/项目组合的关系、项目经理角色、生命周期类型、立项管理，以及"五大过程组"总框架，是后续 ch10–ch14 的总纲。

## Frameworks Introduced
- **项目的定义**：为创造独特产品/服务/成果而进行的**临时性**工作（明确起止 + 独特性）。
- **项目 vs 项目集 vs 项目组合 vs 运营**：项目集协调关联项目获共同收益；项目组合对齐战略；运营是持续性工作。
- **项目成功标准**：达成目标、满足干系人需求与期望、实现商业价值。
- **生命周期类型**：预测型（瀑布）/ 迭代 / 增量 / 适应型（敏捷）/ 混合型。
- **项目立项管理**：项目建议与申请 → 可行性研究（技术/经济/社会/运行/法律/环境）→ 项目评估与决策。
- **五大过程组（总框架）**：启动 → 规划 → 执行 → 监控 → 收尾（本章给总览，各章展开）。
- **价值交付系统**：项目成果 → 业务价值 → 组织战略。

## Key Concepts
- **项目经理**：具备领导力、技术项目管理、战略与商务管理能力。
- **商业论证**：立项与继续投资的依据。
- **渐进明细**：规划随信息增加而迭代细化（区别于范围蔓延）。

## Mental Models
- 判断"这是项目还是运营"：有固定终点且独特=项目；持续重复=运营。
- 立项顺序：建议→可研→评估决策，可研不过不立项。

## Anti-patterns
- 把"渐进明细"当成"范围蔓延"（前者受控、后者失控）。
- 混淆项目组合（战略层）与项目集（收益层）。

## Key Takeaways
1. 项目 = 临时性 + 独特性。
2. 立项三步：建议→可研→评估决策。
3. 生命周期 5 类：预测/迭代/增量/适应/混合。
4. 五大过程组：启动/规划/执行/监控/收尾。
