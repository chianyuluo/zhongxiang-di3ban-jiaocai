# Chapter 18: 职业道德规范

## Core Idea
本章明确信息系统项目管理从业者的职业道德底线：守法、诚信、敬业、保密，强调项目经理在利益冲突、商业秘密与知识产权上的操守，是软考"软素质"必考章。

## Frameworks Introduced
- **职业道德基本原则**：遵纪守法、诚实守信、爱岗敬业、保守秘密、公平竞争。
- **项目经理职业道德**：对客户负责、对团队负责、对社会负责；利益冲突回避。
- **商业秘密保护**：不泄露在项目中知悉的甲方/乙方商业秘密与个人信息。
- **知识产权合规**：尊重他人著作权/专利，规范使用开源与第三方组件。

## Key Concepts
- **利益冲突**：避免自身利益影响职业判断，须主动申报回避。
- **保密义务**：合同与法律双重约束，离职后仍有效。
- **诚信**：不弄虚作假、不串标围标。

## Mental Models
- 遇到"能不能把甲方数据带走/泄给第三方"→ 一律否决，属保密与法律双重红线。
- 投标场景："低价中标后偷工减料"= 违背诚信与质量底线。

## Anti-patterns
- 为拿项目承诺做不到的范围（虚假承诺）。
- 把项目中获得的商业秘密用于其他项目（侵权+违法）。

## Key Takeaways
1. 职业道德四底线：守法/诚信/敬业/保密。
2. 利益冲突须回避；保密义务及于离职后。
3. 尊重知识产权，规范用开源/第三方。
4. 串标围标既违道德也违法。
