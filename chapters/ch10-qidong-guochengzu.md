# Chapter 10: 启动过程组

## Core Idea
启动过程组正式授权项目并识别干系人，是项目的"出生证"阶段。中项第3版启动过程组含 **2 个过程**：制定项目章程、识别干系人。

## Frameworks Introduced
- **启动过程组（2 过程）**：
  1. **制定项目章程**：输出项目章程（正式授权项目经理动用资源），输入含商业论证、协议、SOW；重要输出=项目章程。
  2. **识别干系人**：输出干系人登记册、干系人参与评估矩阵。
- **启动重点工作**：召开项目启动会议（Kick-off）；聚焦价值与目标；明确项目经理权责。
- **项目章程内容**：项目目的、高层级需求、高层级风险、总体里程碑、预批准资源、发起人授权。

## Key Concepts
- **干系人**：影响项目或受项目影响的个人/组织（权力/利益方格分类）。
- **商业论证**：立项与继续投资的依据，章程的输入。
- **Kick-off 会议**：统一目标、明确分工、启动执行。

## Mental Models
- 没有项目章程 = 项目未正式启动，项目经理无权动用资源。
- 识别干系人要"早且全"，漏掉关键干系人后期必返工。

## Anti-patterns
- 跳过章程直接用合同开工（授权链条断裂）。
- 干系人只列"甲方项目经理"，漏掉高层赞助者与终端用户。

## Key Takeaways
1. 启动 2 过程：制定项目章程 + 识别干系人。
2. 章程是正式授权文件，含目标/里程碑/预批资源。
3. 干系人登记册是识别过程的直接输出。
4. 启动会统一目标、启动执行。
