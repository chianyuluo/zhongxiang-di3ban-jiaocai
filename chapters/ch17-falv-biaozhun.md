# Chapter 17: 法律法规和标准规范

## Core Idea
本章汇集信息系统项目必须遵循的法律与标准体系：招投标、政府采购、合同、著作权、网络安全与数据合规，以及标准的分级分类，是合规投标与履约的底线章。

## Frameworks Introduced
- **招标投标法**：公开招标 / 邀请招标；竞争性谈判 / 询价 / 单一来源（非招标方式）；废标与串标认定。
- **政府采购法**：集中采购/分散采购；公开招标为主；政府购买服务边界。
- **合同法（民法典合同编）**：要约与承诺（合同成立）、效力、履行、违约责任、不可抗力。
- **著作权法（软件著作权）**：软件作品自动保护、登记强化举证；职务开发归属单位。
- **网络安全法 / 数据安全法 / 个人信息保护法**：网络运营者安全义务、数据分类分级、个人信息处理合规。
- **标准分级分类**：国标(GB)/行标/地标/企标；强制性(GB) vs 推荐性(GB/T)。

## Key Concepts
- **废标情形**：应招未招、串标、弄虚作假等。
- **不可抗力**：不能预见/避免/克服，可部分或全部免责。
- **数据分类分级**：一般/重要/核心数据，差异化保护。

## Mental Models
- 投标前先判"是否必须公开招标"（金额/性质门槛），再选方式。
- 合同争议先回到"要约—承诺—履行—违约"四步定性。

## Anti-patterns
- 把推荐性标准(GB/T)当强制（只有 GB 强制）。
- 忽视数据安全法/个保法导致项目合规一票否决。

## Key Takeaways
1. 招投标：公开/邀请 + 竞争性谈判/询价/单一来源。
2. 合同成立 = 要约 + 承诺；违约按民法典担责。
3. 软件著作权自动产生，登记强化举证。
4. 合规三法：网络安全法/数据安全法/个保法；标准 GB 强制、GB/T 推荐。
